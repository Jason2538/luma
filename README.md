# Luma

Spotify 계정으로 로그인해서 노래를 검색하고, 내 플레이리스트를 보고, 가사와 함께 재생하는 웹 플레이어예요.

**주소:** https://jason2538.github.io/luma/

## 기능
- 첫 화면 문구가 5초마다 한국어와 영어로 바뀌어요
- 노래·가수 검색 후 바로 재생
- 홈: 오늘의 추천 곡 50개(자주 듣는 아티스트의 새로운 곡 + 좋아하는 곡을 섞음, 새로 고르기) + 내 플레이리스트
- 플레이리스트와 좋아요 표시한 곡은 더 보기 없이 모든 곡을 한 번에 불러와요 (Spotify 모드에도 플레이리스트 카드)
- 재생 화면: 왼쪽은 앨범 커버와 재생 조작, 오른쪽은 재생 시간에 맞춰 움직이는 가사 (무료 가사 서비스 여러 곳을 차례로 찾아요: [LRCLIB](https://lrclib.net) → NetEase → lyrics.ovh, 찾은 가사는 이 기기에 저장, 네트워크 오류 시 자동으로 다시 시도하고 "새로고침" 버튼으로 다시 불러오기)
- 가사 직접 넣기: 가사가 없거나 틀린 곡은 가사 화면 아래 "✎ 가사 넣기"로 가사를 붙여 넣고, 노래를 들으면서 줄이 시작될 때 "탭"(또는 스페이스바)을 눌러 시간을 맞춰요. 되돌리기, ±0.2초 조정, 줄을 눌러 그 줄부터 다시 맞추기, 시간 없이 저장 지원. 내가 넣은 가사는 이 기기에 저장되고 다른 가사보다 먼저 나와요. 이미 있는 가사의 시간을 고칠 때도 써요
- 넣은 가사 공유: 직접 넣은 가사는 친구 서버(Realtime Database `/t/L~곡ID`)에도 올라가서, 다른 사람이 그 곡을 틀면 "OO님이 넣은 가사"로 먼저 나와요. 지우면 서버에서도 지워져요. 설정 → 친구 → "내가 넣은 가사 공유"로 끌 수 있어요
- 재생 화면 오른쪽 위 버튼으로 **가사 · 재생 목록 · 플레이리스트** 전환: 지금 듣는 목록(지난 곡은 흐리게, 지금 곡 표시), 셔플 중이거나 목록 밖 곡이면 Spotify 다음 곡 대기열, 내 플레이리스트를 열어 곡을 바로 고르기
- 곡을 바꿨는데 Spotify가 확실히 다른 곡을 틀고 있으면 같은 요청을 한 번 더 보내고, 그래도 안 되면 "다시 시도" 버튼을 보여줘요 (재생 중인 소리를 끊는 동작은 하지 않아요)
- Luma 재생기가 Spotify와 끊기면(Server error 등) 자동으로 다시 연결해서 듣던 위치부터 이어서 재생하고, 그래도 안 되면 1분 동안 Spotify 앱 기기로 재생해요
- 100곡이 넘는 목록도 끝까지 이어서 재생해요
- 좋아요(즐겨찾기): 곡 줄·플레이어 제목 옆·미니 플레이어의 하트로 바로 넣고 빼요 (Spotify '좋아요 표시한 곡'에 저장, 처음 한 번 권한 추가 로그인)
- 손가락 제스처: 화면을 좌우로 끌면 홈·Spotify·친구 이동(상세 화면은 오른쪽으로 끌면 뒤로), 탭바 위를 끌면 선택 표시가 따라가요, 앨범 커버를 왼쪽/오른쪽으로 쓸면 다음/이전 곡, 아래로 끌면 플레이어 닫기
- 오른쪽 위 기기 버튼으로 다른 기기(폰, 태블릿의 Spotify 앱) 조작
- 아래 탭바(홈 · 검색 · Spotify)와 왼쪽 위 Spotify 버튼
- Spotify 모드: 나를 위한 믹스(많이 들은 아티스트로 Luma가 만듦), 최근 재생한 곡, 많이 들은 곡·아티스트 순위(4주·6개월·전체), 기분·장르 추천, 목록을 내 Spotify 플레이리스트로 저장
  - Spotify가 추천·신곡·장르 둘러보기 API를 막아서, 추천은 내 청취 기록과 검색을 바탕으로 Luma가 직접 만들어요
  - 처음 쓸 때 권한을 추가로 받기 위해 한 번 다시 로그인해야 해요
- 내 재생 시간 통계: 이번 주·지난 주·이번 달·최근 30일·직접 선택 기간의 일별/주별 그래프, 많이 들은 아티스트·곡 (Luma 기록 + Spotify 최근 재생 50곡, 이 기기에만 저장)
  - 오늘(하루) 기록: 시간대별 그래프, 그날 많이 들은 곡·아티스트 순위, 들은 곡을 들은 시각 순으로, 이전/다음 날 이동 (일별 그래프 막대를 누르면 그날 기록으로)
  - 실시간 반영 버튼: 누르면 지금까지 들은 시간과 Spotify 최근 재생을 바로 반영하고, 켜두면 몇 초마다 자동 갱신
- 친구(아래 탭바): Luma에 로그인한 사람끼리 자동으로 친구가 돼요
  - 요약: 이번 주 우리 모두 들은 시간, 지금 듣는 친구, 이번 주 1등, 연속 기록 1등
  - 지금 듣는 중: 친구가 듣는 곡이 실시간(1초 안)으로 바뀌어요. 홈 맨 위에도 '친구가 지금 듣는 중'이 떠요
  - 같이 듣기(따라 듣기): 누르면 친구가 듣는 위치부터 듣고, 친구가 곡을 바꾸거나 멈추거나 넘기면 그대로 따라가요. 내가 직접 다른 곡을 고르거나 조작하면 끝나요
  - 최근 활동: 친구들이 최근 들은 곡과 들은 시각 (누르면 재생)
  - 순위표: 오늘·이번 주·이번 달, 재생 시간·재생 횟수 기준, 연속으로 들은 날 🔥
  - 이번 주 우리가 많이 들은 곡·아티스트 (친구 전체 합산, 누가 들었는지)
  - 친구 순위표(오늘·이번 주 재생 시간), 취향 궁합(많이 들은 아티스트·곡이 겹치는 정도)
  - 친구를 누르면: 이번 주·이번 달·최근 30일·연속 들은 날, 궁합 자세히(아티스트·장르·시간대·겹치는 곡), 재생 시간 비교(오늘·이번 주·이번 달·재생 횟수, 최근 7일, 최근 4주), 듣는 시간대 그래프, 좋아하는 장르, 같이 좋아하는 아티스트, 요즘 많이 듣는 아티스트, 최근 들은 곡, 둘 다 많이 듣는 곡, 이번 주·최근 몇 달 많이 들은 곡
  - 같이 만드는 플레이리스트: 누구나 곡을 넣고(누가 넣었는지 표시) 자기가 넣은 곡은 뺄 수 있어요. 내 Spotify 플레이리스트를 공유해서 시작할 수도 있고, 만든 사람은 Spotify 공동 플레이리스트로 만들어 계속 맞출 수 있어요
  - 설정에서 지금 듣는 곡 공유·재생 기록 공유를 따로 끌 수 있고, 서버에서 내 정보를 지울 수 있어요
- 설정(오른쪽 위 버튼): 기본 재생 위치, 크로스페이드, 자동 재생, 수면 타이머, 음질 안내, 가사 보기·글자 크기, 애니메이션 줄이기, 시작 화면, 로그아웃·데이터 지우기
- APK: 앱을 내리거나 화면을 꺼도 재생이 이어지고, 알림창·잠금화면에서 이전/재생·일시정지/다음 조작 (최근 앱 목록에서 밀어서 닫으면 재생이 끝나요)
- APK 홈 화면 위젯 2가지 (홈 화면 길게 누르기 → 위젯 → Luma): **지금 듣는 곡**(커버·제목·가수·진행바·이전/재생/다음)과 더 큰 **싱크 가사**(이전 줄·지금 줄·다음 줄이 노래에 맞춰 넘어감). Luma에서 재생할 때도, Spotify 앱 등 다른 기기를 조작할 때도 따라가요. Luma 앱이 켜져 있는(최근 앱 목록에 있는) 동안 동기화되고, 밀어서 닫으면 "눌러서 Luma 열기"로 바뀌어요
- APK 설정 → "앱 · 위젯": 위젯 가사 크기(작게~아주 크게), 가사 넘김 효과(없음·서서히·위로 밀기·천천히 밀기), **뒤에서 계속 동기화**(Luma를 내려 두고 Spotify 앱으로 들어도 위젯·친구 공유가 따라가요. 알림이 계속 떠 있어요)
- **Luma를 꺼도 친구에게 보이기**: 친구 동기화 서버(`server/worker.js`, Cloudflare Workers 무료)가 1분마다(20초 간격 3번) Spotify에 물어봐서 지금 듣는 곡·최근 들은 곡을 대신 올려요. 각자 설정 → 친구에서 한 번 켜면 돼요
- 친구 탭 "연결 상태": 내 정보 올리기·친구 정보 받기·실시간 연결이 되는지, 친구별 마지막 소식 시각과 Luma 버전을 보여 줘요. 친구 정보는 Firestore와 실시간 두 길 중 더 새 값을 써요

## 설정 (한 번만)
1. **GitHub Pages 켜기:** 이 저장소의 Settings → Pages에서 Source를 "Deploy from a branch", Branch를 `main` / `/ (root)`로 두고 Save
2. **Spotify 개발자 대시보드** (https://developer.spotify.com/dashboard) 의 앱 Settings에서:
   - Redirect URIs에 `https://jason2538.github.io/luma/` 추가 (끝의 `/` 포함)
   - "Web API"와 "Web Playback SDK" 체크
   - User Management에 사용할 Spotify 계정 이메일 추가 (개발 모드는 최대 5명)

### 친구 기능 서버 (Firebase, 한 번만)
1. https://console.firebase.google.com 에서 프로젝트 만들기 (Google 애널리틱스는 꺼도 돼요)
2. Authentication → 시작하기 → 로그인 방법에서 **익명** 사용 설정
3. Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → 규칙 탭에 이 저장소의 `firestore.rules` 내용을 붙여 넣고 게시
4. Realtime Database → 데이터베이스 만들기 → 위치 `싱가포르(asia-southeast1)` → 잠금 모드 → 규칙 탭에 이 저장소의 `database.rules.json` 내용을 붙여 넣고 게시 (친구가 듣는 곡 실시간 전달용, 없으면 15초마다 새로 받아요)
5. 프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가 → 나오는 `apiKey`와 `projectId`를 `index.html`의 `const FB = { apiKey: '', projectId: '' }`에 넣기
- 무료 요금제(Spark)로 충분해요. 친구 화면이 열려 있을 때만 15초마다 새로 받아 와요.
- 서버 없이 만든 구조라, apiKey를 아는 사람은 친구 정보(이름, 듣는 곡, 재생 기록)를 읽을 수 있어요. 민감한 정보는 올리지 않아요.

## 참고
- 가사는 LRCLIB에서 먼저 찾고, 없으면 NetEase(한국·일본·중국 곡이 많음)에서, 그래도 없으면 lyrics.ovh(시간 정보 없는 가사)에서 찾아요. NetEase는 브라우저에서 바로 호출이 막혀 무료 중계 서버(corsproxy.io, allorigins, codetabs)를 거쳐요. 이때 곡 제목·아티스트 이름만 전달돼요.
- 브라우저 안에서 재생하려면 Spotify Premium이 필요해요.
- 재생 위치는 플레이어 오른쪽 위 기기 버튼에서 고를 수 있어요: **Luma에서 재생**(기본, 이 기기에서 바로 소리가 남) 또는 **Spotify 기기 조작**(Spotify 앱이 켜진 기기).
- 안드로이드에서 Luma 자체 재생은 기기의 DRM 보안 등급(Widevine L1)이 필요해요. Luma에서 소리가 안 나면 3분 동안 Spotify 앱 재생으로 넘어가고, 같은 일이 또 생기면 그 뒤로는 Spotify 앱으로 재생해요. 기기 메뉴에서 "Luma에서 재생"을 누르면 언제든 다시 써요.
- 기본 재생 위치를 "Spotify 앱 조작"으로 정하면 Luma(이 기기)는 켜진 Spotify 앱이 없을 때만 써요.
- Luma 재생기는 Spotify 기기 목록에 "Luma (앱)" 또는 "Luma (웹)"으로 보여요.
- 재생이 이상하면 설정 → 재생 진단 기록에서 기록을 복사해 보내 주세요.
- 내가 만들지 않은 플레이리스트는 Spotify 정책상 곡 목록이 안 보여요. "전체 재생"으로는 들을 수 있어요.
- APK(안드로이드 앱)에서는 Spotify 로그인을 앱 안이 아니라 기기의 브라우저에서 진행하고, 끝나면 앱으로 자동으로 돌아와요. (구글은 앱 안에 들어있는 화면에서 하는 로그인을 막아서, 구글·페이스북 계정으로 가입한 경우에도 이렇게 해야 로그인돼요.)
- Client Secret은 쓰지 않아요 (PKCE 방식). 저장소에 Secret을 올리지 마세요.
- 내 컴퓨터에서 테스트할 때는 `python3 -m http.server 8000` 실행 후 `http://127.0.0.1:8000/`으로 열고, 그 주소도 Redirect URI에 추가하세요. (`localhost`는 Spotify가 받지 않아요)

## 친구 동기화 서버 (Cloudflare Workers, 무료)

친구가 Luma를 켜지 않고 Spotify로만 들어도 보이게 하려면 한 번만 설정해요.

1. <https://dash.cloudflare.com> 에 가입 → **Workers & Pages** → **Create** → Worker 이름을 `luma-sync`로 만들고 Deploy
2. **Edit code**를 눌러 안의 내용을 모두 지우고 `server/worker.js` 내용을 붙여 넣은 뒤 **Deploy**
3. 왼쪽 메뉴 **Storage & Databases → KV** → **Create** → 이름 `luma` 로 만들기
4. Worker의 **Settings → Bindings → Add → KV namespace**: Variable name에 `KV`, 방금 만든 `luma` 선택 → Deploy
5. Worker의 **Settings → Trigger Events → Add → Cron Triggers**: `* * * * *` (1분마다)
6. Worker 주소(`https://luma-sync.<내 이름>.workers.dev`)를 열어 `{"ok":true,"service":"luma-sync",...}`가 보이면 성공
7. 그 주소를 `index.html`의 `LUMA_CONFIG.SYNC_URL`에 넣으면 모든 사용자에게 적용돼요. (넣기 전에는 Luma 설정 → 친구 → "동기화 서버 주소"에 붙여 넣어 내 기기에서만 시험할 수 있어요)
8. 각 사용자가 Luma 설정 → 친구 → **Luma를 꺼도 친구에게 보이기**를 켜요 (Spotify 화면에서 한 번 허용)

- 서버에는 "재생 상태·최근 재생 읽기"만 되는 로그인 열쇠가 따로 저장돼요(KV). 재생 조작이나 플레이리스트 권한은 없어요.
- Luma가 켜져 있어 직접 올리는 중(90초 안에 소식이 있음)인 사람은 서버가 건드리지 않아요.
- 비공개 세션으로 듣는 곡은 올리지 않아요. "지금 듣는 곡 공유"·"재생 기록 공유"를 끄면 서버도 따라요.
- `주소/run` 을 열면 지금 한 번 돌려 보고 결과를 보여 줘요.
